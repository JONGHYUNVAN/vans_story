OAuthController

@RestController
@RequestMapping(value = ["/api/v1/oauth"])
class OAuthController(oauthService: OAuthService)

OAuth 관련 요청을 처리하는 컨트롤러

주요 기능:

  • OAuth 소셜 로그인

  • OAuth 계정 연결/해제

  • 연결된 OAuth 계정 조회

API 엔드포인트:

  • POST /api/v1/oauth/login: OAuth 로그인

  • POST /api/v1/oauth/link: OAuth 계정 연결

  • DELETE /api/v1/oauth/unlink: OAuth 계정 해제

  • GET /api/v1/oauth/linked: 연결된 계정 조회
