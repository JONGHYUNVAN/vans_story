UserMapper

@Component
class UserMapper

User 엔티티와 DTO 간의 변환을 처리하는 매퍼 클래스

주요 기능:

  • 엔티티를 DTO로 변환

  • DTO를 엔티티로 변환

  • 엔티티 업데이트

  • 생성 요청을 엔티티로 변환

사용 예시:

@Autowired
private lateinit var userMapper: UserMapper

// 엔티티를 DTO로 변환
val userDto = userMapper.toDto(user)

// DTO로 엔티티 업데이트
userMapper.updateEntity(userDto, user)

// 생성 요청을 엔티티로 변환
val newUser = userMapper.toEntity(createRequest)
