    Function generateSecureRandomString

    • generateSecureRandomString(length?: number): string

      랜덤한 문자열을 생성합니다.

      암호학적으로 안전한 랜덤 값을 생성하여 nonce, CSRF 토큰 등에 사용할 수 있습니다. 기본적으로 URL-safe한 Base64 문자열을 반환합니다.

      Parameters

      • length: number = 32

        생성할 바이트 길이 (기본값: 32)

      Returns string

      URL-safe Base64로 인코딩된 랜덤 문자열

      Example

      const randomStr = generateSecureRandomString(16);
      console.log(randomStr); // "kJ8x3mP9qR7sT4vW5yZ2aC3dF6gH9jL"
