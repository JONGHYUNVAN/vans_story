# Van's Dev Blog

개발 경험과 결과물을 담는 개인 기술 블로그입니다.

## 🚀 주요 기능

- 타이핑 효과가 있는 인터랙티브한 홈페이지
- 기술 스택 별 블로그 포스팅
- 반응형 디자인

## 🛠 기술 스택

- **Frontend**: React, Next.js
- **Styling**: Tailwind CSS
- **Backend**: Spring Boot (예정)
- **Deploy**: Vercel

## 📂 컴포넌트 구조

이 Storybook에서는 다음과 같은 컴포넌트들을 확인할 수 있습니다:

### UI 컴포넌트
- **Header**: 네비게이션 헤더
- **Sidebar**: 사이드바 네비게이션
- **Button**: 재사용 가능한 버튼 컴포넌트

### Features 컴포넌트
- **Home**: 홈페이지 관련 컴포넌트들
- **Auth**: 인증 관련 컴포넌트들
- **Post**: 포스트 관련 컴포넌트들

## 🎨 디자인 시스템

이 프로젝트는 Tailwind CSS를 기반으로 한 일관된 디자인 시스템을 사용합니다.
